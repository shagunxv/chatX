# 💬 ChatX

A real-time chat application built using **React, Node.js, Express and Socket.IO**.

ChatX allows multiple users to join a conversation and exchange messages in real time through WebSockets.

## 🚀 Live Demo

🌐 **Frontend:**  
https://chat-x-nine.vercel.app

🔗 **Backend:**  
https://chatx-a9jh.onrender.com

---

## ✨ Features

- 🔴 Real-time messaging using Socket.IO
- 👤 Username-based chat joining
- 🟢 Live connection status
- 💬 Instant message broadcasting
- ⏰ Message timestamps
- 📱 Clean and responsive UI
- ⚡ React-based frontend
- 🔌 Node.js + Express backend
- 🌐 Deployed frontend and backend
